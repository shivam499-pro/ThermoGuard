Privacy Policy

Last updated: 20 September 2026 · Built for AWS Builder / Bharat Builds demonstration

ThermoGuard is an investigation-priority research dashboard for satellite thermal anomaly clusters. It is not a consumer social product and it is not a fire-confirmation or emergency-dispatch system.

What we display

The live map shows a curated 100-event pilot cohort derived from public Earth-observation sources (including NASA FIRMS / VIIRS–MODIS detections, Sentinel-2 reflectance indices, OpenStreetMap proximity, and ESA WorldCover class names). Records are identified by synthetic event IDs (for example EVT_…). They are not named individuals.

Personal data

This demonstration does not create user accounts, does not ask for names, emails, or phone numbers, and does not run a login form. We do not sell personal data. We do not run advertising pixels.

Where it runs

The static dashboard is hosted on AWS Amplify. The API is Amazon API Gateway and AWS Lambda in region ap-south-1 (Mumbai). Event records used by the live API are stored in Amazon DynamoDB. AWS processes technical logs (for example CloudWatch request metadata) under AWS’s role as infrastructure provider.

Browsing data

Your browser will request map tiles from OpenStreetMap’s public tile servers and fonts from Google Fonts. Those third parties may see your IP address under their own policies. ThermoGuard itself stores a single optional flag in localStorage if you dismiss the cookie notice (thermoguard-cookie-ok) so the banner does not return every refresh.

Cookies

We do not set advertising or cross-site tracking cookies. See the notice on the dashboard. Map and font vendors are outside this app’s control.
